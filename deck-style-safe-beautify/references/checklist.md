# 交付前检查清单

按顺序打勾。任何一项没勾都不要说「做完了」。

## A. 范围与授权

- [ ] 已把可选做法编号列出，且**只做了用户勾选的项**
- [ ] 已确认：是否允许生图 / 是否保持文件名 / 装饰强度档位
- [ ] 若用了生图，开工前已告知张数与积分消耗区间
- [ ] 用户没点头的可见对象（产品截图、二维码、页眉、进度条、新卡片）**一个都没加**

## B. 风格与素材

- [ ] 已做风格溯源：GitHub 项目 / 在线产品 / 原稿自带截图 / 原稿自身色板（四选一，按优先级）
- [ ] `assets/color-tokens.json` 的 `background.top/bottom/angle_deg` 与原稿一致，并**人工复核过 `accents` 顺序**（第一位是亮色，不是墨蓝）
- [ ] 项目若写明「代码渲染，不是 AI 生成」，装饰以 `decor_recipe.py` 为主
- [ ] 所有生图已过 `strip_watermark.py`：水印清除、透明贴片抠干净（透明占比 40%–85%）、`--audit` 图确认无残字
- [ ] 底色由代码精确还原；AI 图只通过 `--overlay` 贡献高通装饰纹理

## C. 装配

- [ ] 从**原稿**重新装配，没有在成品上替换 `ppt/media/`
- [ ] 每页恰好 1 张全页装饰图，名称带统一前缀（默认 `aigc_bg_`）
- [ ] 装饰层位于 `shapes` 序列 index 1（渐变底板之后、所有内容之前）
- [ ] 没有设置页面级 `p:bg`，渐变底板没被改成 `noFill`
- [ ] `--center-clear` 已开启（默认 0.22），中部装饰强度恒为 0
- [ ] 用 `pick_corners.py` 基于**原稿真实渲染像素**选过角落，没有拍脑袋固定角落
- [ ] 封面/尾页只放极轻装饰，没有和原有主视觉（放大镜/大标题）打架
- [ ] 用户自带的产品截图/图表/Logo 完整保留、无遮挡

## D. 动效（若用户选中②）

- [ ] 只加了 `p:transition`，**没有**生成任何 `p:timing`
- [ ] `p:transition` 位置合法（`clrMapOvr` 之后、`timing` 之前）
- [ ] 原稿自带 `p:timing` 注入前后序列化字节完全一致
- [ ] 效果克制：柔和淡入为主，无声音、无自动换片
- [ ] `--remove` 回滚路径可用

## E. 校验（强制，用独立渲染）

- [ ] 用 `soffice + pdftoppm` 独立渲染原稿与成品，页码集合与 DPI 一致
- [ ] **`verify_zero_change.py` 全项 PASS**，报告已保存
- [ ] 中部正文区渲染差异 < 3.0，差异>15 的像素占比 < 0.01%
- [ ] 四周边缘带渲染差异 > 0.3（证明美化看得出来）
- [ ] 没有用内置截图工具的结论当依据（它有缓存 bug）
- [ ] `soffice --convert-to pdf` 成功，说明 OOXML 合法

## F. 人工目视

- [ ] 封面：橙色放大镜 / 大标题 / 白卡片完整清晰，装饰没抢主视觉
- [ ] 一页内容密集内页：四角装饰明显、正文清晰、风格仍是最初那套
- [ ] 用户自带截图那页：截图完整、无遮挡
- [ ] 一张「原稿 vs 美化」并排对比图已生成，用户能一眼看出差别
- [ ] 20 页（或全部页）缩略拼图通检过，没有配图被白卡片切成一半的残缺

## G. 文件与交付

- [ ] **文件名与输入一致**（「学校-姓名-作品名」这类格式没被改）
- [ ] 原始文件已备份（`*.orig.pptx`）或仍可从上传目录取回
- [ ] 工作区没有残留上一版的素材目录、临时文件
- [ ] 交付说明里明确写了**哪些没做**、**口味档位可调**、**请在 PowerPoint/WPS 里打开确认兼容性**
- [ ] 没有替用户打包票说微软系软件一定兼容手写 XML
- [ ] 预览图与校验报告一并交付
