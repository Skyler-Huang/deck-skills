# 案例复盘：一份 20 页路演 PPT 的四次返工

> **脱敏声明**：本案例已去除学校名、作者姓名、文件名、产品截图与所有原始素材。文中数值来自真实校验输出，但不含任何可识别的个人信息。本包**不包含**原始 PPT 或用户截图。

---

## 背景

一份 20 页的教学产品路演稿，原始视觉：

- 背景：`#BFE9FF`（浅天空蓝，上）→ `#FFFDF0`（暖白，下）的竖直渐变；
- 墨蓝粗标题 + 白底卡片（3px 墨蓝描边 + 实心投影）；
- 四角散落黄/粉/青/绿四角星，封面一个橙色放大镜；
- 第 18 页自带一张真实产品界面截图；
- 原稿每页都有 `p:timing` 逐条出现动画；
- 文件名是「教学产品-学校-姓名-产品名.pptx」格式。

任务：**美化配图和背景，风格不变**。

---

## 返工轨迹

| 轮次 | 做了什么 | 用户反馈 | 根因 |
|---|---|---|---|
| 1 | AI 生成米黄纸纹背景 + 封面插画 + 透明装饰 + 二维码，全 20 页替换背景 | 「不要改我背景风格！你没看见产品风格与我 PPT 一样吗」 | 把「贴近风格」理解成「换一套更好看的风格」 |
| 2 | 撤销；用通行证看在线产品，贴真实界面截图裁片 + 二维码 | 「擅自加产品截图和二维码一点都不美观」「说了 github 上的项目你看看」 | 没溯源到项目源码；把「项目元素」理解成「贴界面」 |
| 3 | 找到 GitHub 仓库，读出锁定色板与「代码渲染，不是 AI 生成」规范；改成代码渲染的极淡装饰层 | 「没有看得出来的美化」「我文件名被你改了」 | 装饰压到氛围级；另存时改了文件名 |
| 4 | 允许生图但锁死同风格；代码还原渐变 + AI 装饰纹理；装饰提到明显档；文件名恢复 | 认可方向，追加要求「语义装饰 + 切换动效」 | — |
| 5 | 按页内容配语义元素 + 注入克制切换动效，③④ 明确不做 | 完成 | 范围先确认，只做勾选的 |

**四轮返工没有一轮是技术做不到，全是理解与沟通问题**。这直接决定了本技能把「铁律」和「范围确认」放在流程最前面，而不是把绘制技巧放在最前面。

---

## 关键发现：项目源码给出的规范

在 GitHub 仓库（作者名与产品空间名对应，但仓库名不同）里读到：

- `app.css` 锁定色板：`INK #17384d`、`SKY #bfe9ff`、`ORANGE #ff6b35`、`YELLOW #ffd23f`、`PINK #ff5d8f`、`PURPLE #a06cd5`、`SOFT #3f6478`、`GREEN #7bd389`；
- 「底色天蓝，孩子的作业纸不该是白的」+ 极淡圆点网格「让大片天蓝有材质」；
- 卡片是 3px 墨蓝描边 + **实心投影**（像厚纸板）；
- 装饰是低透明度胶囊贴纸与浮动放大镜；
- README 明确写：**「多模态是代码渲染，不是 AI 生成，画面由排版、SVG 与 CSS 生成」**；
- `docs/diagrams/` 的注释写着「README 和 PPT 共用一份，避免两处各画然后漂移」。

这一条直接否掉了前两轮的 AI 生图与贴截图路线。

---

## 最终方案

| 层 | 做法 |
|---|---|
| 底色 | 代码按 tokens 逐像素还原 `#BFE9FF→#FFFDF0`，AI 图只贡献高通装饰纹理 |
| 装饰 | 14 个项目里真实存在的元素（放大镜、三/五张卡、信纸信封、册子、徽章、引用卡、贴纸、勾选清单…），统一「暖白纸 + 墨蓝描边 + 实心投影 + 彩色点缀」 |
| 语义 | 按页内容映射：18 张教学设计卡 → 卡片叠层；读者回信 → 信纸；收藏册 → 徽章；逐字标注 → 高亮引用卡 |
| 位置 | 用原稿真实渲染图算四角拥挤度，发现**右上角全稿统一留白**，配图统一收在右上 |
| 层级 | 每页 1 张全页装饰图，放在渐变底板之后、所有内容之前；中部 alpha 乘 0 |
| 动效 | 15 页柔和淡入 + 5 个章节入口推近；原 `p:timing` 全部保留 |
| 没做 | 色质微调、章节背景节奏、任何新增可见对象 |

## 一句话结论

**用户要的是「我这份 PPT 变好看了」，不是「你做的另一份好看的 PPT」。** 这套技能把区分这两件事的一切手段（溯源、色值锁、单一图层、独立渲染、字节级校验）都固化成了脚本；把区分不了时的代价（四次返工）固化成了铁律。
