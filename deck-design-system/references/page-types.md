# Page archetypes

Twelve layouts that cover most product/story decks. Pick before writing coordinates.
Coordinates assume 1280×720 with 72px margins (content band 1136 wide). Budgets are
for body copy; table cells and quotes are separate.

Rule of thumb: if an archetype needs more than one diagram, split the page.

---

## 1. Cover

```
[chip: event / track]
TITLE (52–64pt)            [motif: product mark]
subtitle line (20–22pt)
3 step cards (optional)     -> 340×130 each, 40px gap
footer: audience line
```
- One claim, at most one supporting line.
- Motif must come from the product, not generic clip art.

## 2. Claim (one big statement)

```
kicker 01 / section
TITLE: the claim, 38–44pt
--------------------------------------
one paragraph ≤ 60 chars, 20pt
```
- No cards. Whitespace is the design.
- Use when the point is an argument, not data.

## 3. Data row (3–4 stats)

```
TITLE
[card 340×218] [card 340×218] [card 340×218]
  79/79          515            36/36
  unit chip      unit chip      unit chip
  caption        caption        caption
```
- Numbers 44–72pt; unit as a pill, not inline text.
- Captions ≤ 20 chars, one line.
- 3 is better than 4; 4 only if the fourth is a different kind of number.

## 4. Comparison (A vs B, before/after)

```
TITLE
BEFORE label      |  AFTER label
[box]             |  [box] [box] -> [box]
why it failed     |  why it works
```
- Two states, equal visual weight; the "after" may take more space.
- Put the reason under each state in 13–14pt, not inside the boxes.

## 5. Process (3–4 steps)

```
TITLE
[card] -> [card] -> [card] -> [card]
 01       02        03        04
```
- Max 4 steps; each card 240–300 wide.
- Arrows are a thin line or a small glyph, not a large block.

## 6. Quote / letter

```
TITLE
[paper card with ruled lines]
   "quote, 20pt, ink"
   — attribution, 13pt
```
- Paper feel: off-white fill, 1px border, no shadow, ruled lines at 46px pitch.
- Quote ≤ 3 lines. Attribution is not optional.

## 7. Table (only when rows are truly comparable)

```
TITLE
header row (13pt, accent color, letterspaced)
row 1  |  value  |  how verified
row 2  |  value  |  how verified
```
- Max 5 rows, 3 columns; body 16–18pt, never 10pt.
- Hairlines only, no vertical rules, no zebra fill.
- If a cell needs 3 lines, it is not a table — it is a card.

## 8. Timeline / funnel

```
TITLE
label 1  [========== 100%]
label 2  [======= 78%]
label 3  [==== 56%]
```
- Bars: same height, left-aligned, labels right-aligned outside.
- Show at most 5 bars; annotate the last one with the point.

## 9. Diagram (rings / Venn / 2×2)

```
TITLE
   ( o )   ( o )
      ( o )
   caption explaining the overlap
```
- Circles at 45% opacity, one hairline stroke.
- Labels inside lobes, 10–12pt; never let a stroke cross a label.
- If three labels need explaining, put the explanation outside the diagram.

## 10. Two-panel (claim + evidence)

```
TITLE
[panel A: claim, 60%]  |  [panel B: evidence, 40%]
```
- Panel A is type-only; panel B is a card, chart, or screenshot.
- Divider is a hairline, not a filled block.

## 11. Screenshot hero

```
TITLE
[ product screenshot 900×520, 1px border ]
callout dots + 3 short annotations
```
- Crop to the interesting region; never scale a phone screenshot to full width.
- Annotations: 13pt, one line, with a 1px leader line.
- Add a caption naming what the reader should look at.

## 12. Closing

```
kicker
TITLE (imperative)
link / next step (large)
3 deliverables as chips
```
- One action. A link at 18–22pt, not 12pt.
- No "thank you" alone; give the reader the next move.

---

## Choosing under pressure

| Content shape | Archetype |
|---|---|
| An argument | 2 Claim |
| A measured result | 3 Data row |
| A design decision with alternatives | 4 Comparison |
| How it works | 5 Process / 9 Diagram |
| Proof from the product | 11 Screenshot hero |
| Many small facts | 7 Table (≤5 rows) or split |
| A story beat | 6 Quote |
